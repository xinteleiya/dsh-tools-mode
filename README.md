# dsh-tools-mode · 工具档位

> 一个 DSH 插件：**运行时收放模型手里的工具**，把每轮都带的那一大段工具描述裁掉。
>
> 实测：工具描述从 **132,767 字节 → 14,796 字节**（灵熙档，**-88.9%**）；软糯档 **6,118 字节（-95.4%）**。

## 它解决什么

DSH 每轮请求都会把**全部工具的 schema**放进去（系统提示那一块）。工具一多（100+），这段描述能到 **130KB+**——每一轮都在付这份钱。

这个插件按「档位」收放：**用多大力气干活，就带多少工具**。被收掉的工具**从请求里消失**（不是没权限，是压根不发送）。

## 三档

| 档位 | 工具数 | 干什么 |
|---|---|---|
| `soft` 软糯 | ~13 | 省钱聊天：读记忆、翻旧账、读文件、搜 |
| `ling` 灵熙 | ~22 | 日常：读写、跑脚本、搜、聊 |
| `genius` 天才 | 全量 | 重活：全量工具 |

另外带一个 `hand` 档（~22）：聊天分身专用（传消息 + 读少量资料）。档位可以自己改（见 `index.js` 顶部 `MODES`）。

## 安装

**方式 A：作为插件加进来**

```
dsh plugin add <你的插件路径或 github 仓库>
```

或在插件管理器里「添加 → 本地路径」。

**方式 B：手动挂**

在 `~/.dsh/profiles/<profile>/cordis.patch.yml` 末尾加：

```yaml
- insert:
    - id: tools-mode
      name: '<插件所在路径>'
      config: {}
```

重启 DSH。

## 用法

对模型说「切软糯 / 切灵熙 / 切天才」，或直接调工具：

```
set_tools_mode({ mode: "ling" })
```

仓库里的 `examples/blank.js` 是**最小实现**：只有 `restrict` + 一个示例档 + 怎么加的注释。想自己写/学原理的从这里开始，别从完整版抄。

## 注意

1. **切档会重建一次前缀缓存**（一次代价）——别频繁切，一天切一两次就够；
2. **新注册的工具对老会话不可见**（要新会话）；
3. 默认档建议留全量，日常再切——不然有些自动化脚本会找不到工具；
4. 档位是**白名单**：新装插件的新工具默认不在任何档里，记得加进 `MODES`。

## 原理

`ctx.tools.restrict({ allow })`——把允许的工具名单交给宿主，收掉的工具从请求的 tools 字段消失。
